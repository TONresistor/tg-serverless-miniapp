# MTONGA

A Telegram Serverless demo inspired by Telegram’s [@bugs](https://t.me/bugs) app.

Submit suggestions and issues, vote, comment and follow discussions.
The bot, Mini App and SQLite database are hosted on Telegram.

[Open the Mini App](https://t.me/MTONGA2bot?startapp)

## Structure

- `app/frontend` React, TypeScript and Vite.
- `tgcloud` JavaScript bot handlers, endpoints and database schema.

## Documentation

[Telegram Serverless](https://core.telegram.org/bots/serverless) for setup and deployment.
[App configuration](serverless-settings.example.json) for project-specific settings.
